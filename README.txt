# EsportO Free Website — Phase 1

Files:
- index.html
- style.css
- script.js

How to use:
1. Open index.html in a browser to preview.
2. Replace `your-email@example.com` in script.js with your tournament email.
3. Upload all 3 files to GitHub Pages, Netlify, or another static host.

Important:
This is a front-end demo. It does NOT process real payments, accounts, or automatic tournament brackets yet.
